# CodeAlpha Language Translator

## Description
A simple Language Translation Tool built using HTML, CSS and JavaScript. It uses the MyMemory Translation API to translate text between multiple languages.

## Features
- Translate text into multiple languages
- Beautiful and responsive UI
- Copy translated text
- Swap source and target languages
- Clear input and output

## Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## How to Run
1. Download the project.
2. Open the project in VS Code.
3. Open index.html using Live Server.
4. Start translating text.
